# Joke-API
A beginner-friendly Python CLI that fetches random jokes using a REST API and demonstrates JSON parsing and API error handling.

## 🛠️ Technologies

* Python
* Requests
* REST API
* JSON

## 📚 What I Learned

* What APIs are
* HTTP GET requests
* Request and response
* HTTP status codes
* JSON responses
* `requests` library
* `response.json()`
* `raise_for_status()`
* Exception handling with `try/except`

## ▶️ How to Run

Install the required library:

```bash
pip install requests
```

Run the program:

```bash
python joke.py
```

## 💡 Example

```text
😂 Here's your joke:

Q: Did you hear about the chameleon who couldn't change color?
Ans: They had a reptile dysfunction.
```

## 🎯 Purpose

This project was built as a beginner project to understand how Python communicates with a REST API.
